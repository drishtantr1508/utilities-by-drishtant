# Utilities by Drishtant

> **Personal Application & Computational Tool Suite**  
> Unified operating surface aggregating fine-art photography curation, Indian payroll & TDS simulation, personal workspace, and backend cloud infrastructure.

---

## 🌟 Applications in the Suite

1. **📷 Visual Archive**:
   - Curatorial photography exhibition examining proportion and negative space.
   - Hosted on Netlify Edge CDN with FastAPI on Google Cloud Platform.
   - [visualarchivebydrishtant.netlify.app](https://visualarchivebydrishtant.netlify.app)

2. **🇮🇳 Indian Salary & TDS Calculator**:
   - Section 192 compliant dynamic month-on-month payroll simulator under the New Tax Regime (Budget 2024 / Section 115BAC).
   - Handles variable bonuses, mid-year appraisal hikes, EPF changes, and rupee-exact March true-ups.
   - Designed for deployment on Streamlit Community Cloud (free dedicated container).

3. **📝 Personal Workspace**:
   - Minimalist markdown wiki and document management system.
   - Hosted on GCP Compute Engine daemon (Port 8000).

4. **📍 Address Automation**:
   - Automated logistics parser and postal validation pipeline.

---

## 🚀 Development & Deployment

### Run locally:
```bash
npm install
npm run dev
```

### Build for production:
```bash
npm run build
```

Ready for 1-click deployment on Netlify with the included `netlify.toml`.
